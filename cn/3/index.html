    Chapter 3 The Physical Layer: Transmission¶

    1 Transmission Media¶

    类别 含义 典型介质
    Guided / wired transmission 信号沿物理电缆或导线传播 twisted pair、coaxial cable、fiber optics
    Wireless transmission 信号通过空间中的电磁波传播 terrestrial radio、microwave、infrared、free-space optics、satellite

    1. 1 Persistent Storage¶

    对于极大的数据量，可以把数据写入磁带或固态存储，物理运输存储介质，再在目的地读出。它的传播时延以小时或天计，但每 bit 成本低、有效吞吐量很高。

    1. 2 Twisted Pair¶

    Twisted pair（双绞线）由两根通常约 1 mm 粗、彼此绝缘的铜线组成，两根线以螺旋形式绞合。绞合使不同扭转处的辐射相互抵消，减少天线效应。信号通常表示为两根线之间的差分电压，而不是某根线相对地的绝对电压。外部噪声若同时作用于两根线，差分值变化较小，因此抗噪性更好。

    • 可传输 analog 或 digital information。
    • 带宽取决于线径和传输距离；距离较长时衰减增大，需要 repeater。
    • 典型应用是电话线和 ADSL，也广泛用于 Ethernet。
    • Cat 5e 通常包含四对双绞线：100-Mbps Ethernet 使用其中两对（每个方向一对）；1-Gbps Ethernet 使用全部四对并在各对上同时双向传输。

    类型 特点
    UTP (Unshielded Twisted Pair) 仅有导线和绝缘层，成本低、最常见
    STP (Shielded Twisted Pair) 对线或整根电缆有屏蔽，抗干扰和串扰更强
    SFTP (Shielded Foiled Twisted Pair) 同时采用屏蔽与箔屏蔽

    1. 3 Coaxial Cable¶

    Coaxial cable（同轴电缆）由中心铜芯、绝缘层、圆柱形外导体（常为编织网）和保护外皮构成。外导体提供良好屏蔽，因此相较 UTP 具有更大带宽、可在更长距离以更高速率传输，并具有很好的噪声免疫能力。

    1. 4 Power Lines¶

    电力线原本用于 50–60 Hz 的供电，也可把数据调制信号叠加在低频电力信号上，用于远程抄表、家庭设备控制、家庭 LAN 和宽带接入。

    电力线通信的限制

    电线的电气特性会随房屋和用电设备变化；高频信号衰减较大，电器开关会产生宽频噪声，未经绞合的电线还会拾取并辐射信号。因此系统要避开受保护频段，并使用能抵抗频率选择性衰减和突发错误的方案。短距离上可以取得数百 Mbps 的速率。

    1. 5 Fiber Optics¶

    光纤用于 backbone、high-speed LAN 和 FTTH。光传输系统有三个关键部件：

    1. Light source：LED 或 semiconductor laser，用光脉冲表示 1、无光表示 0。
    2. Transmission medium：极细的玻璃纤维。
    3. Detector：接收端 photodiode 被光击中时产生 electrical pulse，响应速率可达到约 100 Gbps。

    单端光源到单端 photodiode 是 simplex 链路，双向通信通常需要两根光纤或两种波长。

    光从 fused silica 射向空气时会在界面折射，当入射角超过临界角，光线被反射回 silica，几乎不逃逸，这就是导光基础。

    模式 结构 特点
    Single-mode fiber 芯径约 8–10 μm 只传播一个模式，色散小，适合长距离和高速
    Multimode fiber 芯径约 50 μm 可传播多个模式，成本和耦合要求较低，但模式色散更明显

    折射率可以在芯中近似均匀，也可以从中心向边缘逐渐降低（graded-index），以减小不同路径的到达时间差。

    • Light attenuation：输入与输出光功率之比，常以 dB/km 表示，\(A_{dB}=10\log_{10}(P_{final}/P_{initial})\)。

    • Chromatic dispersion：不同波长传播速度不同，使光脉冲逐渐展宽，脉冲重叠后会产生码间干扰和 bit errors。增大脉冲间隔可以避免重叠，但会降低 signaling rate。

    • Soliton：利用 self-phase modulation 抵消色散的特殊脉冲，其形状与双曲余弦的倒数有关。
    • 光纤端接可使用 connector，便于重构但通常损失约 10%–20% 的光功率。
    • Mechanical splice 把切好的两端放入套管并夹紧，约损失 10% 的光，fusion splice 熔接两段光纤，衰减很小但设备和操作要求更高。

    2 Wireless Transmission and the Electromagnetic Spectrum¶

    移动电子会产生可在空间（甚至真空）传播的 electromagnetic wave。把天线接入电路即可把电信号辐射给远端接收机。信号可承载的信息量取决于接收功率，并且与带宽成正比。实际系统通常使用窄频带，以便在有限功率下取得合理数据率。

    2. 1 Spread Spectrum¶

    ① FHSS (Frequency-Hopping Spread Spectrum)¶

    发射机每秒数百次在频率之间跳变。难以侦测和干扰，能抵抗拥挤频段中的衰落与干扰，曾广泛用于军事通信。

    ② DSSS (Direct-Sequence Spread Spectrum)¶

    用 code sequence 把窄带数据扩展到更宽的频带，不同代码的信号可以共享同一频段。

    ③ UWB (Ultra-Wideband)¶

    发送一系列低能量、快速变化的脉冲，快速跃迁使能量稀薄地分布在很宽的频带。

    2. 2 无线传播方式¶

    ① Radio¶

    RF waves 通常是全向的，可以传播很远并穿透建筑物，但容易受到干扰。低频无线电的功率密度大致按距离平方衰减，\(P_r\propto\frac{1}{d^2}\)。

    VLF、LF、MF 波段的地波可沿地球曲率传播，HF、VHF 的地波容易被地面吸收，到达电离层的波会被折射回地面。

    ② Microwave¶

    Microwave 具有方向性，近似沿直线传播，相距很远的塔之间需要 repeater。多径传播会产生 multipath fading，延迟到达的波可能与直达波反相叠加而抵消。工程上可预留约 10% 的信道作为备用，在某个频段暂时衰落时切换使用。

    ③ Infrared¶

    红外线适合短距离通信（电视、蓝光播放器和音响遥控器）。它方向性较强、便宜、易实现，不能穿过固体物体，因此墙外干扰和窃听较少，但也无法穿墙覆盖房间。

    ④ Free-space optics¶

    Free-space optics 用屋顶激光等进行非引导光通信，例如连接两栋建筑物的 LAN。它具有高带宽、低成本、窄光束难以窃听等优点，但需要足够的链路余量。白天太阳加热空气形成对流，使空气湍流把光束偏离接收器。

    3 Transmission Theory¶

    3. 1 Fourier Analysis¶

    可把电压或电流建模为时间函数 \(f(t)\)，任意合理的周期函数都可以分解为直流分量和不同频率的正弦、余弦谐波：

    \[g(t)=c+\sum_{n=1}^{\infty}\left(a_n\sin(2\pi nft)+b_n\cos(2\pi nft)\right)\]

    其中 \(T\) 是周期，\(f=\frac{1}{T}\) 是基频，\(a_n\) 和 \(b_n\) 是第 \(n\) 个谐波的幅度，\(c\) 决定平均值。传输设施会对不同 Fourier component 施加不同衰减，从而造成 distortion。

    3. 2 Bandwidth-Limited Signals¶

    Bandwidth 是介质在不过度衰减的条件下能够传输的频率范围宽度，是介质的物理属性，受结构、厚度、长度和材料影响。

    • Baseband signal：频率从 0 到某个最高频率。
    • Passband signal：把信号搬移到较高的频率范围，以便多个信道共享介质。

    若 bit rate 为 (b) bit/s，发送 8 bit 需要 (8/b) s，其第一谐波约为 (b/8) Hz。若线路只能通过 3000 Hz，最高可通过的谐波约为 (3000/(b/8)=24000/b)，因此带宽限制会限制数据率。

    3. 3 Maximum Data Rate¶

    无噪声信道中，带宽为 (B)、有 (V) 个离散信号电平时，Nyquist 定理给出：

    \[R_{max}=2B\log_2V\quad\text{bits/s}\]

    有噪声时，令信噪比为 (S/N)，其 dB 表示为：

    \[SNR_{dB}=10\log_{10}(S/N)\]

    Shannon 容量为：

    \[C=B\log_2(1+S/N)\quad\text{bits/s}\]

    Nyquist 由带宽和信号电平给出无噪声上限，Shannon 则给出给定噪声条件下的理论容量。

    4 Digital Modulation and Line Coding¶

    Digital modulation 是把数字 bit 转换为代表它们的连续模拟信号（电压、光强或声强），或反向转换的过程。

    4. 1 Baseband and Line Codes¶

    Baseband transmission 常直接用正、负电压表示 1 和 0；光纤中也可用有光表示 1、无光表示 0。NRZ (Non-Return-to-Zero) 在整个 bit 时间内保持电平，不返回参考电平。

    线路编码的目标包括 bandwidth efficiency、clock recovery、DC balance。

    • NRZ 的两电平信号在交替 1/0 时每两个 bit 才可能变化一次；bit rate 为 (B) 时至少需要约 (B/2) Hz 带宽。
    • 使用 (V) 个电平，一个 symbol 可携带 (log_2V) bit。例如四个电平每个 symbol 携带 2 bit。
    • Symbol rate / baud rate 是每秒信号变化（symbol）的次数： \(\(\text{bit rate}=\text{bits per symbol}\times\text{symbol rate}\)\)

    4. 2 Clock Recovery¶

    长串相同的 0 或 1 会使信号长时间不变，接收端难以恢复时钟。

    方法 做法 代价或特点
    Manchester encoding 将时钟与数据 XOR；每个 bit 时间内必有一次转换，经典 Ethernet 使用 需要约两倍 NRZ 带宽，100% overhead
    Transition coding 用转换表示某一 bit、无转换表示另一 bit 长串某一类 bit 仍可能没有转换
    4B/5B 每 4 bit 映射为 5 bit，查表保证不会出现超过 3 个连续 0 25% overhead，常与其他线路码组合
    Scrambling 数据与伪随机序列 XOR；接收端用同一序列再次 XOR 无带宽/时间 overhead，但不能绝对保证没有长串 0 或 1

    4. 3 Balanced Signals¶

    平衡信号在短时间内正、负电压数量大致相等，可以去除 DC component、提供时钟转换并帮助接收器校准。

    • Bipolar / AMI (Alternate Mark Inversion) 使用正、负、零三种电平：0 为零电压，连续的 1 交替使用正、负电压。
    • 8B/10B：把 8 bit 分成 5+3 bit，分别映射成 6+4 bit，再拼成 10 bit。大多数输出保持 0/1 数量平衡；无法直接平衡的输入有两个候选输出（多一个 1 或多一个 0），编码器根据前一 symbol 的 disparity 选择能降低累计偏差的版本。

    5 Passband Digital Modulation¶

    Passband transmission 使用不从 0 开始的频带。把 baseband 的 (0\sim B) Hz 搬移到 (S\sim S+B) Hz 不会改变信息量；接收端可下变频回 baseband。

    载波可以调制三种属性：

    调制 全称 改变的属性
    ASK Amplitude Shift Keying 振幅
    FSK Frequency Shift Keying 频率
    PSK Phase Shift Keying 相位
    • BPSK 在每个 symbol 取 0° 或 180° 两种相位，每 symbol 1 bit。
    • QPSK 使用四种相位（例如 45°、135°、225°、315°），每 symbol 2 bit。
    • QAM (Quadrature Amplitude Modulation) 同时改变振幅和相位；星座图中点到原点的距离表示振幅，点的角度表示相位。常见 QPSK、QAM-16、QAM-64。
    • 为降低相邻星座点误判造成的 bit errors，使用 Gray code：相邻 symbol 的 bit 标签只差 1 个 bit。

    6 Multiplexing¶

    调制只解决一条 bitstream 如何传输；multiplexing 解决多路信号如何共享一条线路。

    6. 1 FDM and OFDM¶

    FDM (Frequency Division Multiplexing) 使用 passband，把频谱切成多个频带，每个用户独占一个频带，并在信道间保留 guard band 防止干扰。例如电话信道可在 4000 Hz 中使用 300–3100 Hz，其余作为保护带。

    OFDM (Orthogonal FDM) 把带宽划分为频域上紧密排列的 subcarriers。每个子载波的频率响应在相邻子载波中心处为 0，因此可在中心频率采样而互不干扰；通过 guard time（通常重复符号的一段）获得所需频率响应。实际实现常用 Fourier transform 一次处理所有子载波。

    一条高速流可拆为多条低速并行流，某个子载波的衰落只影响局部，较容易处理。OFDM 用于 802.11、cable networks、power-line networking 和 4G cellular systems。

    6. 2 TDM¶

    TDM (Time Division Multiplexing) 让用户轮流在 time slot 中使用全部带宽；为容纳时钟误差，slot 之间可插入 guard time。电话和蜂窝网络广泛使用 TDM。

    类型 分配方式
    Synchronous TDM 每个用户在每个 frame 中有固定 slot，即使暂时没有数据也可能浪费带宽
    Statistical TDM 根据需求统计特征动态把 slot 分给有数据的用户；slot 携带 user number，而非固定 frame 位置

    6. 3 CDM / CDMA¶

    CDM (Code Division Multiplexing) 把窄带信号扩展到更宽频带（spread spectrum），抗干扰能力强；多个用户可一直占用整个频谱，通过 code 区分，蜂窝、卫星和有线网络都可使用。

    每个 data bit 用 (m)-chip sequence 编码，bit 时间被分成 (m) 个 chip interval。若某站的代码为

    \[c=(-1,-1,-1,+1,+1,-1,+1,+1)\]

    则 bit 1 发送 (c)，bit 0 发送 (-c)。不同用户使用相互正交或归一化内积很小的代码；接收端将收到的 chip 序列与目标代码做内积即可恢复该用户的 bit，其他正交用户的贡献相互抵消。

    6. 4 WDM¶

    WDM (Wavelength Division Multiplexing) 是光纤中的 FDM：用不同波长的光承载不同信号。DWDM (Dense WDM) 在光纤中安排大量间隔很小的波长信道。

    6. 5 Multiplexing 对比¶

    方式 资源切分 典型直观理解
    FDMA / FDM 每个用户长期占一个子频带 多人并行，各做任务的一部分
    TDMA / TDM 用户轮流占用整个信道的时间片 一次一个用户完成整个任务
    CDMA / CDM 所有用户同时占用全部频谱，用代码区分 每个用户每个时刻发送 chip；每个 data bit 被扩展为多个 chip
    WDM 每个用户占用一条光波长 FDM 在光纤中的实现

    在相同总带宽下，所有方式最终都受共同的最大数据率限制；区别在于资源是在频率、时间、代码还是波长维度上复用。
