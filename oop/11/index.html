    Chapter 11 STL¶

    1 What Is STL¶

    STL
    • STL = Standard Template Library
    • 是 ISO 标准 C++ 库的一部分
    • 提供数据结构与算法

    作者

    • 核心人物是 Alexander Stepanov

    2 Why Use STL¶

    优点

    • 降低开发时间：常用数据结构已写好并调试过
    • 提升可读性：同一页能表达更多有意义内容
    • 更稳健：很多容器会自动扩容
    • 可移植
    • 易维护
    • 易上手

    3 C++ Standard Library Components¶

    标准库中常见部分

    • pair
    • 容器：
      • vector
      • deque
      • list
      • set
      • map
    • 基本算法：
      • sort
      • search
      • copy
      • ...
    命名空间
    • 标准库标识符位于 std 命名空间中

    4 Three Parts of STL¶

    STL 三要素

    • Containers
    • Algorithms
    • Iterators

    5 Common Containers¶

    Top 3

    • map
      • 任意 key 类型 / 任意 value 类型
      • 自动有序
    • vector
      • 类似 C 数组，但可自动扩展
    • list
      • 双向链表

    顺序容器

    • vector：动态数组
    • deque：双端队列
    • list：双向链表
    • forward_list：单向链表
    • array：定长数组
    • string：字符序列

    6 vector¶

    基本用法

    #include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> x;
    for (int a = 0; a < 1000; a++) {
        x.push_back(a);
    }

    vector<int>::iterator p;
    for (p = x.begin(); p < x.end(); p++) {
        cout << *p << " ";
    }
    return 0;
}

    常见操作

    • 构造：
      • vector<Elem> c;
      • vector<Elem> c1(c2);
    • 大小相关：
      • V.size()
      • V.empty()
    • 访问：
      • V.at(index)
      • V[index]
      • V.front()
      • V.back()
    • 增删：
      • V.push_back(e)
      • V.pop_back()
      • V.insert(pos, e)
      • V.erase(pos)
      • V.clear()
    • 比较与交换：
      • == != < > <= >=
      • v1.swap(v2)
    • 迭代器：
      • begin()
      • end()
    效率
    • 注意预估和保留容量
    • 避免不必要的拷贝
    • 已知元素规模时，优先考虑 reserve() 以减少反复扩容

    7 list¶

    List 基本概念

    • 和 vector 一样有构造、比较、首尾访问等概念
    • 支持双端插入删除

    Example

    list<string> s;
s.push_back("hello");
s.push_back("world");
s.push_front("tide");
s.push_front("crimson");
s.push_front("alabama");

list<string>::iterator p;
for (p = s.begin(); p != s.end(); p++) {
    cout << *p << " ";
}
    Tip
    • list 迭代不能写 p < s.end()
    • 因为链表元素在内存中不是随机访问布局

    8 map¶

    Map

    • 保存一组 key -> value 对
    • 查找通过 key 完成
    • 典型例子：电话簿

    Example

    #include <map>
#include <string>

map<string, float> price;
price["snapple"] = 0.75;
price["coke"] = 0.50;

string item;
double total = 0;
while (cin >> item) {
    total += price[item];
}

    9 Algorithms¶

    STL 算法

    • 接受迭代器作为参数，因此可以独立于容器工作
    • 常见查找通常写作 std::find(first, last, item)；有序关联容器如 map / set 也提供自己的 find(key)

    Example

    list<int> L;
vector<int> V;

copy(L.begin(), L.end(), V.begin());

    10 Typedef / using / auto¶

    简化冗长类型名

    map<Name, list<PhoneNum>> phonebook;
map<Name, list<PhoneNum>>::iterator finger;

    可以改为：

    typedef map<Name, list<PhoneNum>> PB;
PB phonebook;
PB::iterator finger;
    Tip
    • C++11 起也可使用 using 和 auto

    11 Using Your Own Classes in STL¶

    可能需要提供的能力

    • 赋值运算符 operator=
    • 默认构造函数
    • 对于有序容器（如 set、map），通常还需要 operator<

    Example

    struct full_name {
    char* first;
    char* last;
    bool operator<(full_name& a) {
        return strcmp(first, a.first) < 0;
    }
};

map<full_name, int> phonebook;

    12 Pitfalls¶

    1. 越界访问 vector

    vector<int> v;
v[100] = 1; // 错误

    解决： * push_back() * 构造时预分配 * resize() * 先检查 size()

    2. map[] 会偷偷插入

    if (foo["bob"] == 1) {
    // 这里可能悄悄创建了键 "bob"
}

    更安全的检查：

    if (foo.count("bob")) { /* ... */ }
// 或 C++20
if (foo.contains("bob")) { /* ... */ }

    3. 判断空容器

    • 慢的写法：
    if (my_list.size() == 0) { /* ... */ }
    • 更直接的写法：
    if (my_list.empty()) { /* ... */ }

    4. 失效迭代器

    list<int> L;
list<int>::iterator li = L.begin();
L.erase(li);
++li; // WRONG

    正确方式：

    li = L.erase(li);
    不同容器的失效规则不同
    • vector 一旦扩容，很多已有迭代器、指针、引用都会失效
    • list 插入通常不会影响其他节点，但被删节点对应的迭代器会立刻失效
