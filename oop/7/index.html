    Chapter 7 Copy Constructor¶

    1 References as Class Members¶

    引用成员

    • 引用成员不能“先声明后赋值”
    • 必须在构造函数初始化列表中完成绑定

    Example

    class X {
public:
    int& m_y;
    X(int& a);
};

X::X(int& a) : m_y(a) {}

    2 Returning References¶

    函数可以返回引用

    • 但返回的引用必须指向仍然存在的对象
    • 通常应返回非局部对象（全局对象、静态对象、调用方传入对象、容器元素等）

    Example

    const int SIZE = 32;
double myarray[SIZE];

double& subscript(const int i) {
    return myarray[i];
}

    调用效果

    double value = subscript(12);
subscript(3) = 34.5;

    3 const in Function Arguments and Returns¶

    参数传递

    • const 值传递通常没有意义
    • 更常见的是 const reference

    Example

    Person(const string& name, int weight);
    优点
    • 不修改实参
    • 避免一次拷贝
    • const 提供接口保护

    const 引用参数

    void func(const int& y, int& z) {
    z = z * 5; // ok
    y += 8;    // error
}

    临时值是 const

    void func(int&);
func(i * 3); // warning / error

    可以理解为：

    const int _tmp_ = i * 3;
func(_tmp_); // 非 const 引用不能绑定到临时常量

    返回值上的 const

    • return const value 基本没意义
    • return const T& / return const T* 是否需要，取决于你是否希望调用方修改返回对象

    4 Copy Constructor Basics¶

    复制发生的本质

    • 用已有对象创建新对象
    • 典型场景：
      • 值传递参数
      • 初始化新对象
      • 函数按值返回

    Example

    void func(Currency p) {
    cout << "X = " << p.dollars();
}

Currency bucks(100, 0);
func(bucks); // bucks 被复制到 p

    拷贝构造函数签名

    T::T(const T&);
    编译器生成的默认拷贝构造
    • 如果你不提供，编译器会自动生成
    • 默认行为是逐成员拷贝（memberwise copy）
    • 对数值、普通对象、对象数组通常没问题
    • 对裸指针则只是复制地址，可能导致共享同一块内存

    5 Raw Pointer Problem and Deep Copy¶

    含裸指针的类

    class Person {
public:
    Person(const char* s);
    ~Person();
    void print();
private:
    char* name;
};

    C 风格字符串

    • 本质是字符数组
    • 结尾有终止符 '\0'
    • "C++" 在内存中实际占 4 个字符

    <cstring> 常用函数

    size_t strlen(const char* s);      // 长度，不含 '\0'
char* strcpy(char* dest, const char* src); // 拷贝字符串

    构造和析构

    Person::Person(const char* s) {
    name = new char[::strlen(s) + 1];
    ::strcpy(name, s);
}

Person::~Person() {
    delete[] name;
}

    深拷贝拷贝构造

    Person::Person(const Person& w) {
    name = new char[::strlen(w.name) + 1];
    ::strcpy(name, w.name);
}
    为什么要自己写
    • 默认拷贝只会复制 name 指针值
    • 两个对象会共享同一块字符数组
    • 析构时可能出现重复释放

    6 Embedded Objects and Default Copy¶

    若成员是 std::string

    class Person {
public:
    Person(const string&);
private:
    string name;
};
    此时默认拷贝通常够用
    • 编译器生成的拷贝构造会递归调用成员对象的拷贝构造
    • std::string 自己已经管理好了资源

    7 When Copy Constructors Are Called¶

    1. 值传递

    void roster(Person);
Person child("Ruby");
roster(child);

    2. 初始化新对象

    Person baby_a("Fred");
Person baby_b = baby_a; // 不是赋值，是拷贝构造
Person baby_c(baby_a);  // 也是拷贝构造

    3. 按值返回

    Person captain() {
    Person player("George");
    return player;
}

Person who = captain();
    拷贝与开销
    • 编译器有时会做 copy elision / RVO 等优化
    • 但程序设计时不能假设所有拷贝都一定被优化掉

    示例

    Person copy_func(Person p) {
    p.print();
    return p; // 可能触发拷贝
}

Person nocopy_func(char* who) {
    return Person(who); // 可能被优化
}

    8 Construction vs Assignment¶

    不要混淆
    • 每个对象只会被构造一次
    • 每个对象应该只被销毁一次
    • 一个已构造好的对象可以被赋值很多次

    9 Copy Constructor Guidelines¶

    实践建议

    • 大多数情况下不用自己写拷贝构造
    • 涉及裸指针、文件句柄等资源管理时要显式定义
    • 若不希望对象可复制：
      • 旧写法：把拷贝构造声明为 private
      • C++11：Person(const Person&) = delete;

    10 static in C++¶

    static 的两层含义

    • 静态存储期：只分配一次，程序期间一直存在
    • 内部链接：名字只在当前源文件中可见

    10.1 File-scope static¶

    文件内隐藏的全局对象/函数

    int g_global;
static int s_local;

void func() { /* ... */ }
static void hidden() { /* ... */ }
    Tip
    • g_global 可通过 extern 在别处声明使用
    • s_local / hidden() 只在当前 .cpp 中可见

    10.2 Function-scope static¶

    函数内静态变量

    • 值在整个程序运行期都保留
    • 初始化只发生一次

    Example

    void f() {
    static int num_calls = 0;
    num_calls++;
}

    10.3 Static Local Objects¶

    Example

    class X {
    X(int, int);
    ~X();
};

void f() {
    static X my_X(10, 20);
}
    Tip
    • 当执行流第一次走到该定义处时构造
    • 最多构造一次
    • 程序结束时析构

    条件构造

    void f(int x) {
    if (x > 10) {
        static X my_X(x, x * 21);
    }
}
    • 只有第一次满足条件时才构造
    • 一旦构造，后续会保留状态

    10.4 Global Objects¶

    Example

    #include "X.h"
static X global_x(12, 34);
static X global_x2(8, 16);
    Tip
    • 它们会在 main() 之前构造
    • 同一文件中按出现顺序构造
    • 在 main() 结束或 exit() 调用时析构

    11 Static Members¶

    静态成员变量

    • 属于整个类，而不是某个对象
    • 只初始化一次
    • 需要在 .cpp 中提供定义（定义处不再写 static）

    静态成员函数

    • 没有隐式接收者 this
    • 只能访问静态成员变量和全局对象
    • 不能参与动态绑定

    使用方式

    ClassName::static_member
obj.static_member
